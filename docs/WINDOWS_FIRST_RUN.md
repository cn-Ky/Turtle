# Windows — ilk açılış

Release ZIP dosyasını çıkarın ve `Turtle.exe` dosyasını çift tıklayın. Bu, konsol penceresi açmayan GUI sürümüdür.

Paket yakalama özelliği için Npcap'in ayrıca kurulu olması ve uygulamanın uygun yetkilerle çalıştırılması gerekebilir. Windows SmartScreen, imzasız uygulama için uyarı gösterebilir.
