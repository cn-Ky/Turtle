Turtle GUI 1.1.0

This repository builds a native desktop GUI application for each target OS using PyInstaller.
- macOS ARM64: Turtle.app (windowed app bundle)
- macOS Intel x86_64: Turtle.app (windowed app bundle)
- Windows x86_64: Turtle.exe (windowed, no console)
- Linux x86_64: Turtle (windowed executable)

GitHub Actions publishes a development prerelease for pushes to main and a regular release for v* tags.
macOS artifacts are not code-signed or notarized because no Apple Developer signing credentials are configured.
